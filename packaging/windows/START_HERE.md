## 一句话流程

双击 **`一键安装并启动.cmd`** → 自动选盘、装工具、装依赖、启动服务 → 自动打开浏览器里的「新机设置」向导 → 在向导里按批准流程下载模型并完成部署。

如果中文文件名在你的解压工具里显示乱码，双击 **`SETUP.cmd`**，两者行为完全一致。

## 先读这一段

本包不包含模型权重、数据库、生成视频、个人素材、API Key 或验收证据。模型由安装向导从固定版本和 SHA-256 的上游地址下载，完整物料约 **60.8 GB**（14 个组件、154 个固定发行包），安装峰值约 **174 GB**，请给非系统盘预留 **180 GiB** 以上。首次安装和下载可能持续较长时间。

打开安装窗口后**不要关闭它**。工具链与依赖装完会自动启动 API、Worker 和 Web，并打开浏览器。后续的模型下载发生在网页里，可以关掉那个黑窗口，但不要关掉 `STOP_APP.cmd` 之外的服务进程。

## 支持的机器

- Windows 10/11 x64
- NVIDIA GPU，显存至少 15.3 GiB（当前基线为 RTX 5080 16GB 级）
- 系统内存至少 30 GiB（32GB 级）
- 非系统盘至少 180 GiB 空闲（安装器会挑选剩余空间最大的可用非系统盘）
- 可访问 GitHub、Hugging Face、PyPI、PyTorch 官方下载源
- 安装前请关闭会拦截 PowerShell 的安全软件；不需要管理员权限

## 安装器会自动决定的事

| 项目 | 自动行为 |
| --- | --- |
| 安装盘 | 选剩余空间最大的非系统盘，装到 `<盘符>:\ShineVideoStudio` |
| 工具链 | 按 `config/deployment/tools-windows-x64.json` 的固定版本与 SHA-256 下载安装 |
| Python / 前端依赖 | `uv sync --locked` + `npm ci`，缓存目录全部放在安装盘 |
| 数据目录 | `<安装盘>:\ShineVideoStudio\data` |
| 操作员密码 | 自动生成 24 位随机密码，写入 `<安装盘>:\ShineVideoStudio\operator-credentials.txt` |
| 端口 | 默认 API 8000 / Web 5173；被占用时自动顺延并在窗口里提示 |
| 浏览器 | 安装成功后自动打开 `http://127.0.0.1:<端口>/#setup` |

**操作员密码**用于在网页里批准安装计划、实例计划和配置激活。安装结束后请打开 `operator-credentials.txt` 抄下密码，然后删除该文件。它不会出现在日志或窗口输出里。

## 在向导里要做的事

「新机设置」按顺序走：

1. 环境检查
2. 部署清单（14 个组件、154 个包）
3. 生成安装计划
4. 人工批准（需要操作员密码）
5. 执行下载与安装（约 60.8 GB）
6. 实例步骤
7. 登记工作流
8. 生成受管配置
9. **验证服务与工作流**（短暂启动受管 ComfyUI 与审片服务，读取真实 `/object_info` 和 `/v1/models`，生成密封证据后关闭）
10. 就绪检查

**每张计划都需要单独一次人工批准，这是产品门禁，不是安装失败。** 第 9 步是新增步骤：它会把 L4「真实服务与节点契约」从 `PENDING` 变成 `READY`，并把 8B 视觉审片与 0.6B 语音审片的路由绑定到实际安装的模型。

## 再次启动 / 停止 / 体检

| 目的 | 操作 |
| --- | --- |
| 再次启动 | 双击 `START_APP.cmd` |
| 停止服务 | 双击 `STOP_APP.cmd` |
| 只读体检（磁盘 + 工具链） | 双击 `CHECK_ENVIRONMENT.cmd`，不写任何文件 |

重复双击 `一键安装并启动.cmd` 是安全的：已经装好就只启动并打开向导，已经在运行就直接打开向导，不会装第二遍。

## 验收口径

`PASSED` 只表示**生产完成**，不等于验收通过。任务行上的 `acceptance_status` 才是验收结论：

- `accepted`：最新一次 `final` 门真实通过
- `pending_review`：生产完成但 `final` 门要求人工复核
- `rejected`：`final` 门判不通过
- `mock`：Mock 调度，从未产生真实视频
- `not_run`：还没跑到验收

不要把「页面变绿」「任务 PASSED」「下载完成」当作成片验收。

## 当前仍然是 PARTIAL 的部分

- 全量 60.8 GB 下载与 14 组件安装尚未在干净 Windows 上完整跑通。
- 受管实例首次真实加载 H3（含首启参数）尚未实机验证。
- 约 60 秒、至少两人对白、多场景的 M4 成片尚未跑出来。
- 因此本包适合**安装链与真实环境联调**，不应把安装成功当作完整生产验收。

## 已收口的 P0（相对上一版）

- 审片路由不再缺失：向导第 9 步会创建并绑定 `local-vlm-hash-verified` / `local-asr-hash-verified`。
- L4 不再固定 `PENDING`：由密封服务证据计算，配置、配方、工作流合同或审片能力任一变化都会失效。
- 审片模型身份按实际安装发现（8B 视觉 / 0.6B 语音），不再写死 4B 标签。
- 子进程临时目录补上 `TMPDIR`，不再回落到系统盘。
- 生产完成与验收结论分离（`acceptance_status`）。
- 文档磁盘预算、包数量与实际清单一致（180 GiB / 154 包 / 60.8 GB）。

## 实机测试记录要求

遇到失败时请记录以下内容，不要只发一张红字截图：

1. 包名、构建号、Windows 版本、GPU 型号/显存、系统内存、目标盘剩余空间。
2. 安装窗口的完整文字（安装器会同时写一份 `install-log-*.txt` 到安装目录）。
3. `CHECK_ENVIRONMENT.cmd` 的完整输出。
4. 失败发生在哪一步：选盘、工具下载、依赖安装、服务启动、计划生成、审批、下载、实例、模型绑定、工作流登记、服务验证、就绪检查、真实生产。
5. 原始错误码，例如 `PACKAGE_FILES_NOT_VERIFIED`、`INSUFFICIENT_DISK`、`COMFY_STARTUP_ARGUMENTS_INVALID`、`SERVICE_VALIDATION_WINDOWS_ONLY`。
6. 是否完成了完整 60.8 GB 下载；不要用「下载了一部分」冒充完整安装。
7. 如果涉及真实视频，请提供镜头数、时长、角色数、对白人数和门禁状态。不要提交未获授权的私人素材。
