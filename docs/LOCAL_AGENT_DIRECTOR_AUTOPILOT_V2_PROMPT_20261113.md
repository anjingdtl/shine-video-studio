## 目标用户体验（不允许变成新工程后台）

导演模式只保留 **七个清晰创作步骤**，普通用户只管故事、分集风格、镜头、必要素材、拍摄授权和成片审片：

① 导入小说/剧本 → 直接编辑大纲 → 一次确认；文学四阶段与五维记忆后台负责长文本和场次。
② 只选导演风格、真人/动画、集数、每集秒数 → 看真实分镜书 → 一次确认冻结分集和风格。
③ 一次后台五工种分镜 → 按集镜头表 → 一次确认当前集/选中已就绪集；失败场局部重做。
④ 只从已确认镜头派生素材需求，按角色/造型/场景/道具/音色真实需要去重；已有素材复用，缺项用户明确选择制作/上传/跳过，用户自己选定候选成为主素材并一次回绑。
⑤ 只把已准备好的集形成冻结导演包，不被其他未完成集阻断。
⑥ 导演界面仅一个真实 H3 开拍入口，使用已登记本机 Ref2VA INT8 的已验证 Profile，复用 Run/Series/Job 和 GPU 调度，不许另起同类队列。
⑦ 已完成镜头自动衔接已有装配/字幕/技术质检，按集展示可审片 MP4，人工决定最终艺术认可和定向返修。

在导演模式移除重复挂载的四阶段旧 UI、旧分镜、旧素材分析和多套开拍面板；**不是删除后台能力**，专业模式必须继续可用。首页显示本集进度、唯一下一主操作与具名待办，不要展示 UUID、JSON、工程状态码来要求小白排障。依照 V2 文档统一只读按集状态投影，绝不新建第二份阶段事实台账。
