# 一页说明：把制作环境准备好（给普通用户）

> 你只需要记住一件事：**所有环境准备都在「设置 → 制作环境」这一页完成。**

## 第一次使用

1. 打开工作台，点左下角「设置」，进入「制作环境」。
2. 页面会**自己检查**这台电脑：显卡、内存、磁盘、已装的 ComfyUI、已有模型。
   不需要先点任何按钮；想再看一次就点右上角「重新检查」。
3. 看页面顶部那一句结论，照它做：
   - **已经找到你的 ComfyUI** → 直接下一步；
   - **找到不止一套** → 点一次你要用的那套，之后不会反复问；
   - **什么都没有** → 点「准备环境」，系统会用它自己的目录装一套。
4. 勾选你要的能力（H3 视频 / 素材出图 / 画面审片 / 语音核对），点一次确认。
   确认框里写着这次要下载多少、装到哪个目录、会不会动你原有的 ComfyUI。
5. 点「开始准备」之后就可以离开这一页了。

## 准备的时候能做什么

- **可以关掉网页**：下载、核验、登记、生成运行配置、核对服务都由后台服务继续。
- **可以切到导演模式**写剧本、拆镜头：环境准备不会被打断。
- **重新打开页面**会看到最新进度，不会从头再来。

## 页面上的五步是什么意思

| 步骤 | 意思 |
| --- | --- |
| 检测本机 | 看一眼这台电脑有什么，只读，不改任何文件 |
| 文件整备 | 缺的模型按固定清单下载，已有的不重复下载 |
| 自动登记 | 已经核验过的文件自动记账，**不需要你点"登记"** |
| 绑定与运行核对 | 让 ComfyUI 真正读得到这些文件，并核对节点 |
| 真实试镜 | 用你的方案真出一次片，这一步会单独问你 |

## 下载不动了怎么办

1. 能力卡上会写「缺少 N 个文件」，点开能看到每个文件的**下载链接、大小、保存目录**。
2. 用浏览器手动下载，**保持原文件名**，放进页面给出的那个目录
   （默认是 `<安装目录>\manual-downloads\<清单>\<组件>\`）。
3. 回到页面点「重新检查」，系统会自己校验、导入并继续安装。原文件不会被删。

## 常见疑问

**「已经找到出图资源，正在完善本机运行配置」是什么？**
说明文件已经有了，只差一份能启动的配置。点一次「完善本机运行配置」，
后台会补齐；这不是让你去选技术方案。

**ComfyUI 正被别的程序用着，会不会被关掉？**
不会。工作台不会终止不属于它的进程。如果它确实占着显卡，页面会告诉你
"需要空闲后才能开始制作"，你关掉那个程序再点「重新检查」即可。

**会不会重复下载几十 GB？**
不会。已有且核验过的文件会直接复用；只有缺失或校验不通过的文件才会重新获取。

**这些按钮是不是都要点一遍？**
不需要。正常情况下你只会点两次：**一次确认准备**，以及**第一次真实试镜**。
