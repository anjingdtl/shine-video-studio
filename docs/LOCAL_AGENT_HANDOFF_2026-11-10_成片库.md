## 新增成片库

在工作台提供明显的「成片库」按钮，进入当前项目的本机视频管理页。复用现有媒体、Job、镜头、分集、批次和交付台账，按项目查询。覆盖实际落盘的单镜或分段、分集或成片、历史版本和返工版本，清楚标明当前采用、历史、待审、缺失等状态。不要把同一 artifact 因为有多个交付回执重复展示，也不要把缩略图和连续性派生图当成成片条目。

- 每条显示项目名、集号或未分集、镜号或范围、镜头名称、类型、版本和状态。时长、分辨率、生成时间、大小可用时显示。一个成片含多镜时，从真实 EDL 或交付范围读取归属。历史记录缺字段时明确显示缺失，禁止从排序、文件名或猜测补齐。
- 每条有预览图，优先复用已有视频 poster 和缩略图缓存，并支持点开播放。预览图来自对应版本的实际视频，缺失时显示占位与状态。保留「打开所在文件夹」作为本机文件入口。预览和管理不要自动下载或创建第二份 MP4。
- 支持多选和「批量删除」。当前页全选与跨页选择范围要让用户看得清。确认界面显示项目、选中数、将删除的文件和无法删除的项。按已有本机 Operator / 同源保护接入，服务端只接受本项目的 artifact ID，由台账解析并验证路径范围。活动任务、当前采用版本、仍被有效成片或连续性关系引用的源文件，以及路径异常项需要按现有不变量阻止或明确核对。删除可删除的历史条目后，保持 Job、交付回执、审计和实际磁盘状态一致。处理共享文件、已缺失文件、重复请求、部分失败与操作竞争。历史证据不得因为文件删除而被改写为另一个版本。所有破坏性验收用隔离样本，禁止删除正式六镜、三镜和 v2。
- 用户要求实际生成的视频文件名带项目、镜号、集号，不能只改下载名或列表显示名。建议单镜格式为 `《项目名称_003镜_02集》.mp4`，多镜成片用 `《项目名称_001-006镜_02集》.mp4`。没有已确认集号时用「未分集」，范围不明时显示「镜号未登记」。`*` 是字段占位，不进入 Windows 文件名。确定 Windows 非法字符、保留名、同名项目、重拍版本、路径长度及 Unicode 的处理。版本冲突可加简短版本后缀或在不同版本目录分隔。保持 SHA-256、存储身份、已有引用和恢复一致。新增输出走正式落盘路径，旧视频仍可播放和管理。批量迁移旧文件如确有必要，应单独设计并验证，不要擅自复制或重命名正式验收产物。
