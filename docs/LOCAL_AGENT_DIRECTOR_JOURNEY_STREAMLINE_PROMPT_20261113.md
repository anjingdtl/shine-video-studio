# 本地 Agent 自主建设与验收提示词

```text
你负责在本地完成 Shine 视频工作台导演模式收束改造，并自主审查、修复、测试和验收，直到能说明每个目标是否达成。持续做完实际实现和验证，遇到可恢复故障自行定位、修复并从断点重验。

仓库为 https://github.com/anjingdtl/shine-video-studio
本地项目为 F:\ClaudeWorkSpace\projects\shine-video-studio
已知 ComfyUI 目录为 F:\AIGC2026\ComfyUI_Mie_2026_V8.0_Base，请核对当前实际登记的工作流、节点和权重。
方案分支为 origin/feature/director-journey-streamline-20261113
主方案为 docs/SHINE_DIRECTOR_JOURNEY_STREAMLINE_PLAN_20261113.md

先 fetch origin，核对当前工作树、远端方案分支、远端 main 和本地正在进行的工作。优先用独立 worktree 从方案分支建立本地实施分支，保留现有改动、测试数据库和正在运行的项目。主分支如有新提交，先检查差异和本任务交叉点，再按需纳入并记录实际实施基线。读完主方案、AGENTS.md、仓库基线和 2026-11-13 全旅程穿测报告，再开始改代码。实际环境以探测结果为准，验收使用隔离数据目录。

按以下目标实施：

1. ① 创意与剧本。导入小说或成稿剧本后，主界面直接展示可编辑的大纲正文。用户在同一处改完并点一次「确认大纲」就冻结实际编辑内容。删除普通路径上的补充锁定事实输入和重复确认。文学四阶段与五维故事记忆在后台执行，保留来源、场次标识、版本和局部失效。远端文本发送继续走已有授权。
2. ② 剧本统筹。主界面只留导演风格、影片类型、集数、每集目标秒数。一次生成按集、场、节拍、对白和预计时长展示的分镜书，一次确认该分集和风格。默认优先集数，时长有偏差时在预览中显示并允许改。沿用现有导演风格模板、分集计划和冻结版本。
3. ③ 镜头拆解。一次触发后台分镜，按集展示可编辑的镜头表。区分镜间切开/接拍、镜内切点、成片时长和 H3 生成片段长度。把逐场应用、计划落镜和分集重复确认收成「确认本集镜头」。同一场或镜头失败可局部续作和手改，独立集可继续。修复真实 schema 拒绝的停摆路径。能从已返回内容补齐的字段由程序处理，关键内容不全才暂停相关范围，已成功结果保留。
4. 分镜五工种继续按原角色和模型路由执行，接入文学四阶段同一套弹性上下文预算。预算覆盖实际完整请求与推理开销，按现有 60% 输出上限及更严的模型、配置与窗口限制执行。不要只记录上下文窗口或提高固定输出上限。遇到超预算先按相关性压缩或拆场，保留当前场关键事实。继承既有流式、限流和 UNKNOWN 对账，未知结果不盲重发。
5. ④ 拍摄素材准备。由已确认镜头的需求生成清单，按实体和造型去重并列出用到的镜头。复用、上传、AI 制作与可选项跳过由用户在一张表决定。只将明确选中制作的项送现有素材中心。候选由用户选定，随后用既有采用与版本检查批量回绑，刷新后能恢复进度。禁止静默晋升候选、替换主素材或对未选中的缺项发起 AI 任务。
6. ⑤导演包、⑥视频生产、⑦后期成片只修订交接与范围。能用已就绪的完整集形成有效导演包并从正常入口开拍。只预检本次范围和真实依赖。复用现有 Run/Series/Job、Worker、统一调度、QC、字幕、装配与导出。第一集已完成、第二集待修时能先交付第一集。补完第二集后从断点继续，第一集不重拍。
7. MiniMax-H3 规则包只在最终提示词制作时作为写作指引，导演创作和提示词草稿允许自然语言。保留唯一 H3PromptCompiler 和内部可执行字段的确定性校验。正式执行只走本地经验证的 ComfyUI + MiniMax-H3，使用实际登记的工作流与模式。确认必要引用、时码和本机工作流映射。可选缺项只提示，真实 Ref2VA 主体、音频或参考槽位问题定位到相关镜头。不要改用其他视频模型、云生成路径或未验证工作流。

自主执行相关代码修改、迁移（确有必要时）、开发环境修复、定向回归、前端构建、Windows 启停验证、真实浏览器穿测和本地提交。沿用现有测试和台账，保护已通过的镜头和交付物。复查幂等性、跨项目与范围隔离、旧数据兼容、版本并发、部分失败与恢复。自审从用户点击入口向后追踪到实际产物，发现阻滞立即修复并重验。将实施和验收留在本地功能分支，汇报待审提交。

验收按方案第 11 节执行。先跑相关后端测试、Ruff、前端类型检查、全量前端测试与构建，再用 Windows 的正常启动入口进行真实穿测：

- 用原创或授权短篇建立两集项目，通过浏览器导入、修改并冻结大纲、生成分镜书和镜头。第二集通过正常界面留一场待处理。
- 第一集复用一项素材，明确选择一项交给素材中心制作，选定候选并回绑。通过真实本地 H3 出片、质检、播放并导出 MP4。
- 刷新或重启隔离环境，补完第二集并导出。比对第一集 Job ID、镜头产物及成片哈希，证明第一集未重跑。
- 用旧项目副本验证原始大纲、镜头、风格、素材、导演包和交付仍可读取并继续。用工程测试验证坏格式、部分失败、断流及 UNKNOWN 等可控异常，业务实测通过普通界面完成，不用手改台账或绕过入口。

最终交付本地代码提交、测试结果与验收报告。报告包括实际基线、改动与剩余问题、被验收提交、测试命令与数量、Windows/H3 工作流、两集的真实任务与交付证据、用户操作次数和各阶段耗时。把工程通过、真机真实出片和人工审片分别说明。真实模型、GPU 或人审证据不足的项目标记为未验证，列出具体阻塞与最短复验步骤。测试素材、输出、数据库、凭据和未脱敏日志留在本机。
```
