The comfy-cli command implementation (`comfy_cli/command/custom_nodes/command.py`) was also inspected at its pinned revision: `save-snapshot` delegates to Manager and accepts `--output`. Manager `cm-cli.py` lines 1040–1074 define the same option. ComfyUI `server.py` defines read-only inventory routes, `/queue`, and `/free` with `unload_models`/`free_memory`.

Qwen3-TTS checkpoint capabilities are distinct: 1.7B VoiceDesign, 1.7B/0.6B Base cloning, and CustomVoice predefined speakers. Qwen3-ASR 0.6B/1.7B and ForcedAligner 0.6B were found in the official README. ForcedAligner documents up to five minutes and eleven languages. These are upstream declarations, not local acceptance.

The Qwen TTS/ASR source repositories carry Apache-2.0. Exact weight revision, model-card license, quantization/derivative licenses, all weight hashes, and runtime requirements remain unverified; reference entries are deliberately not installable packages. Qwen-Image-2.1 LICENSE explicitly restricts use to non-commercial research/evaluation absent a separate commercial license. Never infer weight permissions from code licensing.

ComfyUI/Manager remain independently installed components. Existing GPL plugin boundaries and the pinned H3 rules/workflow hashes are preserved. No upstream Python was vendored. HTTP image/voice service endpoints are explicitly Shine adapter contracts, not claims about official Qwen or ComfyUI HTTP APIs.
