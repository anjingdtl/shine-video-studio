## API, schema and files

[API reference](V1.3_API_REFERENCE.md) lists every additive method/path and request schema.
All use the existing `/api/v1` application. Requests reject unknown fields. High-risk actions
use authenticated operator dependencies and grants rather than a client-supplied `user` actor.

New migration tables: `comfy_instances`, `environment_snapshots`, `model_packages`,
`node_packages`, `installation_plans`, `installation_attempts`, `workflow_revisions`,
`rights_records`, `candidate_assets`, `voice_profiles`, `voice_renders`, `preproduction_plans`,
`asset_requirements`, `preparation_approval_grants`, `resource_leases`.
Existing `Asset`, `Project`, `AgentTaskRecord`, Job/Attempt/QC and `AuditEvent` remain authoritative.
There is no second project database, renderer, H3 prompt compiler or autonomous approval service.

New source modules:

- `backend/shine/api_preparation.py`: all preparation API contracts, human gates and orchestration.
- `backend/shine/comfyops/{models,approval,inventory,installer,local,registry,assets,images,preproduction,scheduler,tasks,fake}.py`
  and `reference_catalog.json`: persistence, probes, safe executor algorithms, local CLI, registries,
  candidate/rights integration, providers, readiness and compute admission.
- `backend/shine/voiceops/providers.py`: typed design/clone/TTS/ASR/aligner ports, Fake test tones,
  explicit loopback service client, text/time checks and subtitle formatting.
- `backend/alembic/versions/f130a0010001_preproduction.py` and
  `f130a0020001_pin_preproduction.py` (exact manifest binding for queued jobs).
- `frontend/src/components/PreproductionPanel.tsx`, connected from `App.tsx`.

An optional Alembic metadata check found the historical `assets.tags` nullable mismatch;
the ORM now reflects the existing nullable column and the API normalizes NULL to `[]`.
No parent-table recreation or historical-row update was performed.

Existing `main.py`, `worker.py`, `config.py`, `models.py`, `schemas.py`, film contracts and
ComfyUI client are incrementally extended. The Fake ComfyUI fixture gains `/free`; no old
assertions/tests are removed. Only old migration-head expectations advance to the new head.

## License and local boundaries

See [the pinned source audit](V1.3_UPSTREAM_AUDIT.md). Qwen-Image-2.1 non-commercial research
restrictions were read in its exact license. TTS/ASR source Apache-2.0 does not establish every
weight/quantization/model-card permission. Reference-only models have no invented SHA/weight
revision or installable state. H3 and independent plugins retain their separate license review.

The following are explicit constraints, not hidden successful capabilities:

- **PENDING_LOCAL_ENV:** real Windows discovery, actual Comfy instances/node/Python/extra-root
  differences, local service bridge to exact installed model SDKs and runtime loading. Cloud
  tests implement the same HTTP/client and installer logic with Fake executors/servers.
- **PENDING_LOCAL_ENV:** real downloads and instance binding. The local installer verifies files
  in an app-owned isolated root; it deliberately does not run arbitrary node dependency hooks.
  Third-party dependency execution/production-instance upgrades remain separately authorized
  local operations. L3 existing-instance mutation is **BLOCKED** by the HTTP planner.
- **PENDING_LOCAL_GPU:** image/edit/VoiceDesign/clone/TTS/ASR/VLM, exact weight/precision/VRAM
  feasibility, real model release, H3 PDD8/upscale publication and film/audio/voice/lip-sync QC.
- **BLOCKED until verified local capabilities exist:** production publication for unimplemented
  local music/SFX/action/interpolation/assembly or other category-specific templates. All families
  retain import/requirements/gap paths; catalog classification does not claim a working generator.
- Script extraction is conservative and annotation-based. Free-prose completeness and per-shot
  outfit/prop detail must be inspected/supplemented through typed requirements before the human
  freezes the manifest. Optional requirements are visible, never silently counted as satisfied.
- Technical candidate QC performs full FFmpeg decoding. Real semantic quality remains human/local
  reviewer acceptance; the cloud's semantic labels are explicitly Mock. A Fake tone is not speech.
- GPU budgets remain estimates. Expiry does not prove physical model release; ambiguous leases
  block until reconciled. A whole machine or multi-package install is not claimed to be atomically
  recoverable merely because each package swap has a journal/backup.

No actual model weights, third-party ComfyUI nodes, real H3/GPU inference, user-machine directories,
private media, production databases or credentials were accessed/committed during this work.
Production authority and real model-quality acceptance remain with the local human operator.
