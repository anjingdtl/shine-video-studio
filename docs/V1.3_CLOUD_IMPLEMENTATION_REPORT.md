## Verification and boundaries

The acceptance run uses temporary databases/files, synthetic media, Fake SDK models,
Fake HTTP and FakeCommandRunner against production adapter code. It includes the original
film crew/compiler/Worker/repair/archive loop, then checks old manifest invalidation without
rewriting passed artifacts. Independent baseline counterexamples remain archived.
Local full regression passed 373 tests; three focused provenance checks passed after the
last follow-up. The isolated browser covers twelve control flows with no API errors.
Final command logs and the exact same-SHA CI run are recorded in the adversarial review;
intermediate runs are not substituted for final head acceptance.

`TESTED_OFFLINE` proves deterministic software behavior. `MOCK_VERIFIED` proves adapter and
orchestration behavior using synthetic providers; neither proves model quality or GPU feasibility.
Actual Windows paths/configuration, licensed package files/downloads/install execution are
`PENDING_LOCAL_ENV`. Model load/unload measurements, peak VRAM/speed, H3 output, voice identity,
image semantics, lip sync and human playback are `PENDING_LOCAL_GPU`.

Unknown models/nodes/media transports, strict continuity, or unverified generator categories
are `BLOCKED` until their actual contracts/evidence are registered. This is a runtime capability
restriction, not a claim that a fabricated template or generic import is a working generator.
Qwen Base unsupported emotion/speed/pause fails explicitly. Its ASR lacks speaker/confidence
proof by default; human listening is mandatory and the original evidence remains unchanged.
No local bridge program needs to be written: configure the delivered SDK/image adapters.

The [local checklist](V1.3_LOCAL_INTEGRATION_CHECKLIST.md) covers real connection, authorization,
execution and audiovisual acceptance. Cloud never downloaded real weights, installed third-party
nodes, started real ComfyUI, accessed the user's machine or forged production approval.
No main push, force push or merge is authorized. Optional GitHub screenshot storage may be blocked
by artifact quota; the browser assertions and log remain mandatory.
