# Shine Assets 素材整备中心使用说明

Shine Assets 是 Shine Director 旁边的独立工作台。直接打开 `#a/home` 即可开始，不必先创建影视项目。素材库保存在本机数据库与现有内容寻址文件存储中；打开专业设置可查看模型、工作流和队列诊断。

## 建立第一项全局素材

1. 进入“全局素材库”或“图片工坊”，导入本机授权的图片/音频。
2. 填写素材来源、许可名称与授权说明。跨作品使用须明确勾选允许范围；许可到期、撤销或用途不符时，系统会拒绝新任务/分配。
3. 导入素材会建立候选版本。运行技术检查并由你人工审核、晋升后，才可以分配给项目。
4. 全局素材条目有自己的版本树和收藏状态。生成的新候选不会覆盖当前正式版；人工晋升才会改变全局默认版本。

## 图片工坊

- **文生图**：写画面描述，选长宽和候选数。正式生成只在当前本机能力已验证时开放。能力未验证时，只有本机工作流完整可执行时才显示“运行一次本机验证样例”。
- **图生图**：第一张图片是编辑底图，可附更多语义参考。编辑指令和每个实际输入 SHA/顺序一起进入版本记录。
- **局部修订**：画布按底图真实像素绘制遮罩，白色区域取 Qwen 生成像素，黑色区域逐像素保留原图。遮罩必须非空、非全幅且尺寸相同。官方编辑图没有原生 mask 输入，所以这个模式只有完成真实本机小样后才会显示为可正式生成。
- **多图合成**：按顺序标注人物、服装、鞋帽、配饰、道具、场景等语义槽。当前官方样例公开 10 个总槽位，第一张是目标；超过上限或漏传的输入会被拒绝。
- **人物穿戴**：把人物作为第一张主体图，服装/鞋帽/配饰使用各自槽位。候选分别保留，不会覆盖人物原版本。
- **透明背景/移除背景**：导入一张 PNG，在画布上把白色涂到需要保留的主体，黑色区域会被写成真正透明像素。该手工遮罩路径不调用图像模型。提示词生成透明背景仍需真实模型输出证明透明 alpha；没有证据时状态保持待本机验证。
- **候选与正式版**：任务完成只是待审候选。技术检查成功不等于语义合格或有商业许可。通过人工审核、授权和一次性确认后晋升。

## 声音工坊

- 导入对白、音色授权样本、音效和音乐，并选择分类、播放和检索。
- “设计音色”“授权克隆”和“普通话对白”只有本机对应声音服务可用时才会排队。授权克隆需要真实 WAV 样本、说话人授权和授权期限。
- 新音色必须试听后人工冻结；TTS 只能使用有效且已冻结的全局音色。已有的 ASR、词级对齐和对白质量门禁继续生效。
- 目前没有已验证的独立音效/音乐生成模型；该分类只提供导入管理。

## 图片与声音排队

图片和声音共用本机串行队列，一次只运行一项 GPU 任务；H3 视频生产优先使用显卡，素材任务会等待。一个素材模型阶段结束后，后台服务先确认模型已经卸载、显存占用已释放，再开始下一阶段或下一项任务。无法确认时任务会停在等待核对状态，不会因为等待超时而抢占显卡。

## 与导演工作台互通

- 在“项目分配”选择影视项目、已晋升全局版本、角色/场景身份和用途。服务端会创建新的项目素材 ID，并验证项目授权及当前剧本素材需求。
- 导演工作台素材准备页可按人物/场景/道具需求搜索全局已晋升版本，并将其复制为当前项目独立身份。
- 项目中已锁定的素材可以显式“保存到素材中心”成为全局候选，完成来源和授权确认后审核晋升。
- 全局 V2 不会改变已经冻结引用 V1 的旧项目。不同项目可以复用相同物理文件，但拥有独立项目素材身份、角色名、用途范围和记录。

## 状态与诊断

任务状态和能力状态分开显示。页面刷新只重新读取已有任务；不会二次提交生成。UNKNOWN 任务只提供读取 ComfyUI 既有 history 的“对账”。只有服务端证明原请求没有提交时，才可通过明确确认建立一个全新任务身份。

模型与素材授权必须分别核对。Qwen-Image-2.1 上游使用 2026-09-20 research license，不代表商业授权。不要上传无权处理的真人图片、声音或第三方素材。
