# V1.3 local execution and acceptance checklist

This list is for connecting real equipment, executing reviewed packages and accepting actual
media. The instance lifecycle, dependency installer, local image/voice adapters, workflow
factory and Web controls are implemented in the repository. No bridge programming or cloud
software development is delegated to the local operator. See the exact verification status
and evidence in [the adversarial review](V1.3_ADVERSARIAL_REVIEW.md).

## PENDING_LOCAL_ENV — connection and authorized execution

1. Preserve production SQLite, media, 8188/8189 instances, workflows and environments. Use
   SQLite backup into a disposable acceptance workspace first. Run migrations against the copy.
   Keep `SHINE_OFFLINE_SIMULATION` unset for production. Never use the public test credential.
2. Provision the human `SHINE_OPERATOR_ID` and `SHINE_OPERATOR_TOKEN_SHA256` following
   [operator-review.md](operator-review.md). Enter plaintext only into the in-memory password
   field or prompted CLI input; never URL, browser storage, Git or logs.
3. Configure JSON `SHINE_COMFY_PROBE_ROOTS` and `SHINE_COMFY_PROBE_PORTS` with exact authorized
   paths/ports. In Environment choose local mode, inspect execution-context, optionally narrow
   the scope, then scan. Verify Chinese paths, disk space, GPU/driver, Python, Comfy and node
   versions. Repeat scans must append snapshots without duplicating current instance identity.
4. Back up existing external instances through the read-only backup-plan control. Select the
   exact allowlisted root and instance ID, inspect plan hash, approve, execute while idle and
   compare backup/source hashes. Production is never silently adopted or overwritten.
5. Review exact model/weight/node/wheel sources and licenses, including derivative/quantization
   rights. Qwen-Image-2.1 requires separate commercial permission. Register actual immutable
   revisions, file sizes/SHA256, dependencies, resource state and runtime_versions. Catalog
   references with unknown hashes are not installable packages.
6. Import actual offline files using Package ID + manifest relative_path, or authorize a local
   download plan. The server checks real free space in addition to the entered plan budget.
   Approve the exact expiring hash. Enable `SHINE_ENABLE_LOCAL_EXECUTION=1` only on the acceptance
   Windows machine; execute in the Web controls or prompted package CLI:

   ```powershell
   uv run --project backend python -m shine.comfyops.local PLAN_ID APPROVED_PLAN_SHA256 --execute
   ```

7. Generate a separate CREATE instance plan with fixed source package and all pinned dependency
   wheels. Review root/Python digest/argv/L2 risk. INSTALL_NODE, BIND_MODELS, START, STOP, SNAPSHOT,
   RESTORE and ROLLBACK are separate L3 plans and approvals. Python dependencies use offline
   wheel hashes; missing wheels block. No arbitrary setup hooks or global comfy-cli stop.
8. Check actual health and idle queue. Snapshot and verify a disposable instance before changes.
   Exercise interruption only on that instance. Read attempts; reconcile a dead verified owner,
   inspect the preserved backup, separately approve ROLLBACK. Do not delete unknown/live locks,
   retry an uncertain command or kill an unowned process. Keep existing external backups protected.
9. Configure delivered providers, then restart API:
   - `SHINE_IMAGE_COMFY_URL=http://127.0.0.1:PORT`: direct Comfy image adapter.
   - `SHINE_VOICE_SDK_PACKAGES` JSON maps `design`, `base`, `asr`, `align` to registered exact
     ModelPackage IDs. Install the pinned SDK dependencies in the selected runtime, from reviewed
     files; the bridge imports them lazily and uses local_files_only. No custom HTTP bridge is needed.
   Optional existing `SHINE_LOCAL_IMAGE_URL`/`SHINE_LOCAL_VOICE_URL` remain Shine HTTP adapters,
   not official Qwen endpoint claims. Defaults stay Fake. A UI label never changes backend provenance.

## PENDING_LOCAL_ENV / PENDING_LOCAL_GPU — actual capability registration

  `6f7a5fb19c548ca945f8a2169e05c836d7c06f03466cf2b893b3be599505d112` and
  `7d86f7b6d994b0b38cc379a4fe0268f68776c4a43e80fb0f7651a3005f57dcd6`.
  Assemble audited drafts or register an actual API graph. Bind exact model/node dependencies,
  modes, reference slots/transfers, duration/ratio, instance and resource constraints.
- Use live object_info validation and actual installed revisions. A missing node version or media
  mapping remains BLOCKED. Soft references do not establish strict continuity. Register the real
  PDD8/upscale profile separately; do not replace historical workflow/model identity.

  human promotion precede candidate local-evidence and a separate publish grant. For generic
  non-video workflows, submit actual History/output digest with workflow_validate authority.
  H3 evidence requires a current, human-reviewed real Job/Attempt/Artifact and five real gates.
  Use the existing isolated pre-production acceptance project to establish the initial H3
  evidence before analyzing the production project; never disable an analyzed project's gate.
- Check publication, deprecation, historical revision lookup and dependency-version mismatch.
  Unknown nodes/models, music/SFX generators, hard continuity or unverified media capabilities
  remain BLOCKED until their actual registered contract and local evidence establish support.

## PENDING_LOCAL_GPU — loading, performance and audiovisual acceptance

- Measure actual VRAM/RAM, peak/load/unload times and image/voice/H3 throughput. Exercise exclusive
  H3, other queued models, OOM, release failure and restart. /free acknowledgement is insufficient:
  idle queue and allocation counters must confirm release. Unknown state retains the lease.
- Generate/import real character/outfit/location/prop/storyboard/keyframe/action/audio/subtitle
  candidates. Keep source/rights/reference/project/version evidence. Decode fully; inspect semantic
  findings/model/confidence. Explicit human promotion preserves original QC and provenance.
- Design/clone separate checkpoints; approved reusable sample/conditioning drives exact frozen
  Voice Profile versions. Clone consent is not execution authority: authorize each request and
  later dialogue separately. Test consent withdrawal and wrong reference. Listen before freezing.
- Check Chinese text and real ASR/alignment, SRT/ASS exports and playback. Qwen Base rejects
  unsupported emotion/speed/pause; do not silently treat ignored controls as supported. ASR with
  unknown speaker/confidence requires human listening; text/timing errors remain hard failures.
- Analyze the existing structured script: scenes/shots/characters/outfits/props/voice/exact lines
  and dependencies must remain critical. Inspect conservative free-prose annotations and add
  typed requirements where needed. Freeze Style/Rule/Asset/Voice/Workflow manifest as a human.
- Produce one real H3 shot, then a short dependent/independent sequence with QC and repair.
  Confirm revoked used references stop queued/submitted/review paths while independent shots
  continue. New freezes must not authorize older queued pins; passed historical outputs survive.
- Verify duration/dimensions/FPS/audio, every frame, voice identity/lip sync, PDD8/upscale, real
  visual continuity and final human playback. Preserve historical distinction: old 480×864 failed
  production visual acceptance; separate 2016×1152 basic acceptance is not full-film acceptance.

For each local item preserve UTC, named human, project/plan/task/attempt IDs, source commit/license,
package/workflow/content hashes, exact hardware/driver/runtime versions, commands, VRAM/time,
local media location, review findings, known failures and rollback outcome. Keep all weights,
private media, credentials and production databases out of Git.
