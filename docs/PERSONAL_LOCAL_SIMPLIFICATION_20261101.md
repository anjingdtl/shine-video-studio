# 个人本机部署：素材与环境流程简化

用户于 2026-11-01 明确授权移除操作员密码和上传素材的手填核验依据，简化素材配置及新机准备流程。本修订覆盖旧基线中强制配置操作员凭据的要求。基线代码 `e10f471`，实现分支 `codex/simplify-local-setup`。

## 用户看到的行为

1. 上传素材只需选择用途和文件，自动识别图片、视频、音频；名称默认取文件名。角色名称、标签保留为可选展开项。
2. 点击一次「确认使用」或「确认使用全部待确认素材」，确认内容和使用权后，程序依次取得当前版本授权、批准、重新取得版本授权、锁定。中途失败刷新真实状态，保留已完成部分；再次点击只处理尚未完成的操作。
3. 风格冻结、素材确认、安装、目录设置、人工审片等本机页面均无需输入操作员密码。安装器不再生成、展示或要求抄录密码；重复启动不依赖凭据是否存在。
4. 新机设置默认只显示「检测本机环境」。检查通过后显示目录、空间与「下载缺项并自动配置」。确认提示包含完整清单体积、目录、第三方组件与服务启动范围。
5. 确认后依次检查网络、已有安装状态、下载校验、实例准备、工作流登记、配置生成、服务验证、配置激活。通过状态必须由服务器实际返回；详细表格和手动维护入口折叠为高级详情。

## 边界

- 本机免密操作使用 `X-Shine-Local-Action: 1` 标记和现有 loopback / Origin 检查；拒绝跨站 Fetch Metadata。该标记用于防跨站请求，不能证明请求来自特定真人。记录身份为 `local-user`，不冒充经过密码认证的操作员。
- 显式携带旧 Bearer 凭据的脚本继续验证原凭据；错误凭据不会转成免密成功。历史凭据、项目数据库、素材、任务与证据不清理、不重写。
- 一次性 grant、版本/内容快照、素材真实文件哈希、候选资产晋升条件、风格冻结、GPU 租约、云端素材授权和不确定提交的对账规则继续生效。
- 下载/实例执行失败、未知状态、未完成的旧计划、服务验证失败都会停止。页面关闭或切换后，已经发出的操作保留记录；不会继续启动后续实例和激活步骤。
- 自动配置当前需要先创建一个项目，以沿用唯一数据库中的计划归属。基础工具缺失仍由「一键安装并启动.cmd」自动补齐；硬件、驱动及磁盘不足明确提示，网页不自动修改系统驱动。
- 本轮未执行数十 GB 的真实下载、新机从零安装或真实 H3 推理；软件回归不能替代这些验收。
