# Shine Launcher Windows x64

This ZIP contains the Windows x64 Shine Launcher executable, SHA-256 sidecar,
build identity, and license notices. The executable is built with the software
renderer and does not require the Studio Python, Node, ComfyUI, or GPU runtime
to open.

The current engineering preview supports local read-only checks, legacy
installation discovery, and an explicit GitHub release metadata scan. It does
not install or update Studio, run AI capabilities, or update itself. The
publisher trust store is empty and remote installation remains disabled.

Windows 10/11 GUI startup, Chinese rendering, clean-machine launch, and legacy
upgrade/recovery remain `PENDING_LOCAL_ACCEPTANCE` until verified on a Windows
machine.
